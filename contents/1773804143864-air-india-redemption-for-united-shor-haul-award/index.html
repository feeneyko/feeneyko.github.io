印度航空里程兑换美联航短途攻略（绕过限制方法）
#

印度航空有很实惠的点数兑换表，可以用作美联航短途兑换*：

  • <700：3.5k
  • 700–1000：5.5k
  • 1000–1600：7.5k
  • 1600+：13.5k

问题：官网限制美国国内航线搜索
#

目前印度航空官网新增了限制，许多两个美国机场（例如 IAD → ROC）之间的奖励兑换被禁止搜索。

分析：通过 Network 请求发现限制来源
#

使用浏览器开发者工具（F12 → Network），可以看到在选择出发机场（例如 IAD）时，会发送如下请求：

fetch("https://api.airindia.com/airport-info/v1/destinations?origin=IAD", {
  "headers": {
    "accept": "application/json, text/plain, */*",
    "accept-language": "en-US,en;q=0.9,zh-CN;q=0.8,zh-TW;q=0.7,zh;q=0.6",
    "ocp-apim-subscription-key": "8ea658f3ac1e44cca129d7ed252d4c42",
    "priority": "u=1, i",
    "sec-ch-ua": "\"Not:A-Brand\";v=\"99\", \"Google Chrome\";v=\"145\", \"Chromium\";v=\"145\"",
    "sec-ch-ua-mobile": "?0",
    "sec-ch-ua-platform": "\"Windows\"",
    "sec-fetch-dest": "empty",
    "sec-fetch-mode": "cors",
    "sec-fetch-site": "same-site"
  },
  "referrer": "https://www.airindia.com/",
  "body": null,
  "method": "GET",
  "mode": "cors",
  "credentials": "omit"
});

返回结果是一系列允许选择的目的地机场：

{
  "code": "0",
  "message": "",
  "extendedMessage": "",
  "status": "SUCCESS",
  "hasError": false,
  "responsePayload": {
    "data": [
      { "airportCode": "ADL" },
      { "airportCode": "AGR" },
      { "airportCode": "ASP" },
      ...
      { "airportCode": "ASB" }
    ]
  }
}

可以看到：前端是通过 API 限制“可选目的地”。

解决方法：拦截并修改 fetch 请求
#

通过重写 fetch，可以让网页“以为”请求的是 IAD，但实际上返回 BOM 的数据，从而解锁更多目的地。

（将如下内容粘贴至Console）

const originalFetch = window.fetch;

window.fetch = async function(input, init) {
  let url = typeof input === "string" ? input : input.url;

  if (url.includes("/airport-info/v1/destinations?origin=IAD")) {
    url = url.replace("origin=IAD", "origin=BOM");
    console.log("modified url:", url);

    if (typeof input === "string") {
      input = url;
    } else {
      input = new Request(url, input);
    }
  }

  return originalFetch.call(this, input, init);
};

可以修改IAD至任意想要的出发机场。

效果
#

这样就可以：

  • 出发地仍然选择 IAD
  • 目的地可以手动选择 ROC

成功搜索并兑换：

IAD → ROC = 3,500 points

注意事项
#

  • 仅当United提供该航班X舱奖励票 时可兑换

  • 印度航空目前存在以下问题：

    • ❌ 无法立即购买积分（注册后需等待约 15 天）
    • ❌ 注册 / 登录验证码有概率报错
